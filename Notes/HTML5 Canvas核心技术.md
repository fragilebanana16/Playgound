

#### Canvas 的宽高通过HTML 属性和 **CSS** 设置

| 设置方式                   | 作用                                   |      |
| :------------------------- | :------------------------------------- | :--- |
| HTML 属性 `width`/`height` | 定义画布的实际像素尺寸（位图大小）     |      |
| CSS `width`/`height`       | 定义画布在页面上显示的尺寸（拉伸缩放） |      |

默认尺寸就是 **300 × 150 像素**，二者不一致时以属性为准再被 CSS 拉伸
